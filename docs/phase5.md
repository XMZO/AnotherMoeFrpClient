## 实现了什么

- **网络代理**（6.10）：
  - 新增"自定义"模式，支持 `http://`、`https://`、`socks5://`。
  - API 请求、检查更新、图片下载都走同一套代理设置。回环地址永远直连。
  - 自定义地址要点"应用"才生效，填错时给出格式提示，不会切过去。
- **开机自启**（6.8，`internal/autostart`）：
  - 写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\MoeFrp`，内容是 `"<exe>" --autostart`，不需要管理员权限。
  - 每次启动时核对一次：exe 换了位置时会重写路径。
  - 端到端构建的值名带数据目录的哈希，不会碰正式版的那一项。
- **`--autostart` 启动**：只显示托盘，不创建窗口，也就不启动 WebView2。点托盘或再次启动 exe 时才创建窗口。
- **启动后自动连接**：开关打开后，启动时自动运行上次的配置和节点（`TunnelService.StartLast`）。
- **隐藏到托盘时释放 WebView2**（6.8，PLAN 里写的是"试做"）：
  - 实测效果好，所以**做成了默认开启**，设置里可以改回"只隐藏窗口"。
  - 窗口关闭后，前端重新打开时从 Go 端恢复全部状态。
- **检查更新和公告**（6.12，`services/update.go`）：
  - 启动时检查一次，之后每 6 小时一次；失败时 15 分钟后重试。
  - 新版本和公告各推送一次事件。前端用 localStorage 记住已经提示过的版本和公告，重开窗口不会重复弹出。
  - 当前版本低于最低版本时，提示里会说明"账号和同步已停止，本地配置仍可启动"。
  - 开发版（版本号解析不了，例如 `dev`）不提示。
- **图片面板**（6.9，`services/image.go`、`components/ImagePanel.vue`）：
  - 在左侧导航栏底部，每 60 秒换一张；窗口不可见时不换，释放 WebView2 后也就不换了。
  - 按权重选图源，失败时依次换下一个。
  - 单张最大 15MB，只接受 image/*。缓存在 `%LOCALAPPDATA%\MoeFrp\images\`，只保留最新 30 张。
  - 前端通过 `/moefrp-img/<id>` 显示图片，由资源处理器从缓存目录取。ID 只允许 32 位十六进制。
  - 复制时先转成 PNG 再放进剪贴板，支持 jpeg、png、gif、webp、bmp。
- **"关于"页**：检查更新、更新说明、SHA256、公告、开源许可列表。
- 新增错误码都有中文提示：`image_*`、`clipboard_failed`、`autostart_failed`、`proxy_url_invalid`。
- 设置文件的结构版本升到 2，新增 `proxyUrl`、`autoStart`、`imagePanel`、`releaseOnHide`。旧文件读入时，图片面板和释放内存这两项按默认开启处理。

## 与 PLAN 不一致或需要你决定的地方

1. **"隐藏到托盘时释放 WebView2"默认开启**。PLAN 写的是"试做，效果不好就保留隐藏窗口"。实测重开窗口只要 0.57 秒，后台内存从 512MB 降到 51MB，所以默认开启。代价是窗口里没保存的输入（例如正在填的表单）会丢失，正在编辑的抽屉、弹窗也会关掉。
2. **图片面板放在左侧导航栏底部**，导航栏从 150px 加宽到 170px。旧版放在主界面右侧，新版的主界面空间要留给配置编辑。
3. **图片每 60 秒换一张**，旧版是 20 秒。图源都是外部网站，60 秒更省流量，对图源也更友好。
4. **客户端里没有写死任何图源**，全部由服务端配置下发。服务端没配图源时，图片面板显示"暂时没有可用的图源"。图源在管理后台"设置"页里编辑（也可以在 `config.toml` 里配置 `[[client.image_sources]]`），"填入推荐图源"会加上旧版客户端内置的四个。
5. **开机自启以注册表为准**：设置里开着，但注册表里的值被别的软件删掉时，下次启动会自动补上。如果用户想彻底关掉，需要在设置里关。

## 怎么运行

```powershell
cd E:\frp_end\gogogo\client
wails3 build PACKAGE_MANAGER=pnpm EXTRA_TAGS=e2e APP_NAME=MoeFrp-e2e
node .\scripts\e2e\run-phase5.mjs     # 约 2 分钟
```

正式版 `bin\MoeFrp.exe` 体积 20.1MB，比 Phase 4 多约 0.4MB（图片解码和剪贴板）。
