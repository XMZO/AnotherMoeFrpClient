# 客户端实时通道

登录后的客户端和面板保持一条 WebSocket（`GET /api/v1/client/live`，和其他接口一样用 Bearer 会话令牌认证）：

- 面板这边一有变化（云端配置、订阅、官方节点、限额、密钥、客户端版本），马上推给客户端，不用等下一次轮询（轮询每 60 秒一次，仍然保留作兜底）；
- 管理员通过它远程控制客户端：推送通知、停止 / 重启隧道、让设备下线；
- 客户端把自己的隧道状态报给面板，后台"客户端"页据此显示在线设备。

通道只是加速：断开期间照常靠轮询同步，断线、被拒绝都只记日志，按退避（1 秒到 30 秒，带抖动）重连。

代码：`shared/api/live.go`（消息格式）、`server/internal/live`（面板侧的连接管理）、`server/internal/httpapi/live.go`（接口和后台操作）、`client/internal/live`（客户端）、`client/internal/services/live.go`、`notice.go`。

## 消息

帧都是 JSON 文本 `{"type": "...", ...}`，按类型只填对应的字段（`api.LiveMessage`）。

面板 → 客户端：

| type | 什么时候 | 客户端怎么做 |
|---|---|---|
| `welcome` | 连上后第一条，带面板时间 | — |
| `sync` | 这个用户在别的设备上改了云端配置、订阅；分享者改了 / 重新发布 / 撤销了他订阅的分享 | 马上同步一次 |
| `official` | 官方节点列表、在线状态、限额、权限、访问地址可能变了（300 毫秒内合并成一次） | 带 ETag 拉一次官方节点 |
| `tickets` | 登录票据作废了：轮换面板主密钥（所有人）、重置某个用户的节点凭证（这个用户） | 丢掉预取的票据；正在用官方节点的马上用新票据重连 |
| `config` | 后台改了客户端版本、最低版本、公告 | 重新检查更新、显示公告；最低版本提高了的话，下一次请求被拒绝，账号功能随之停用 |
| `notice` | 管理员推送的通知 | 右上角通知或弹窗，可以带一个打开链接的按钮 |
| `tunnel` | 管理员远程停止 / 重启隧道 | 执行，并告诉用户是管理员操作的、原因是什么 |
| `ended` | 会话结束了（被踢、改密码、账号停用、单设备模式下被挤下线），带原因 | 按被动下线处理，然后面板断开连接 |

客户端 → 面板：

| type | 内容 |
|---|---|
| `hello` | 客户端版本、系统名称（例如 Windows 11 专业版 24H2）、主机名 |
| `status` | 隧道状态：状态、配置种类（本地 / 云端 / 订阅）、配置名、节点名、官方节点 ID、启用的代理数、正在运行的代理数、错误原因。不含地址、令牌等配置细节 |

## 面板侧

- 每个会话只保留一条连接，新连接顶掉旧的。发送队列满（对方卡住）时丢弃消息，不阻塞推送方。25 秒 ping 一次，20 秒没回应断开。
- 会话被吊销（退出登录、被踢、改密码、停用账号、改角色、单设备模式挤下线）后，面板检查所有在线连接，无效的发 `ended` 再断开。
- 最低版本检查和普通接口一样：版本过低的客户端连不上通道（426）。管理后台的接口不受最低版本限制。

## 管理后台"客户端"页

- **在线设备**：用户、设备（主机名、系统）、客户端版本（比最新版本旧的标"可更新"）、隧道（状态、配置种类、节点、运行中 / 启用的代理数）、IP、上线时间。3 秒刷新一次，可以按"隧道运行中""需要更新"筛选、搜索。
- **推送通知**：发给全部在线 / 普通用户 / 管理员 / 选中的设备；级别（信息、成功、警告、错误）；显示方式（右上角通知，或要点"知道了"的弹窗）；标题、内容、按钮文字和链接（只能是 http(s)）；可以设成不自动消失；带预览。窗口隐藏到托盘时通知先存着（最多 20 条），打开窗口后一起显示。
- **远程停止 / 重启隧道**：单台或批量，可以写原因（显示给用户）。没在运行隧道的设备不受影响。
- **下线**：吊销选中设备的会话，客户端马上回到未登录（本地配置不受影响）。要禁止登录到"用户"页停用账号。
- **版本与公告**：最新版本、最低版本（强制更新：比它旧的客户端立即停用账号功能，只能用本地配置，直到更新）、下载地址、SHA-256、更新说明、公告。保存后立即推给所有在线客户端；也可以"恢复为配置文件"。存在数据库 `settings.client_config` 里，优先于配置文件的 `[client]`。

所有操作写审计日志（`admin.client_notice`、`admin.client_tunnel`、`admin.client_kick`、`admin.client_config`）。

## 接口

| 接口 | 说明 |
|---|---|
| `GET /api/v1/client/live` | 客户端：实时通道（WebSocket） |
| `GET /api/v1/admin/clients` | 在线设备 |
| `POST /api/v1/admin/clients/notice` | `{target, notice}` 推送通知，返回发出去的数量 |
| `POST /api/v1/admin/clients/tunnel` | `{target, action: stop / restart, reason}` |
| `POST /api/v1/admin/clients/kick` | `{sessions: [会话 ID]}` |
| `GET / PUT / DELETE /api/v1/admin/client-config` | 客户端版本、最低版本、下载地址、更新说明、公告；DELETE 恢复为配置文件 |

`target` 是 `{all, roles: [...], users: [用户 ID], sessions: [会话 ID]}`，各条件之间是"或"。

## 测试

- `server/internal/httpapi/live_test.go`：在线设备和隧道状态、通知（含校验）、远程重启、别的设备改配置推 `sync`、限额推 `official`、重置凭证推 `tickets`、改客户端版本推 `config` 且最低版本立即生效、后台让设备下线推 `ended` 并断开。
- `client/scripts/e2e/run-official.mjs`：真实客户端上，后台看得到设备和隧道状态、推送通知能显示、轮换密钥后客户端用新票据重连（实测 0.6 秒左右）、远程停止隧道。
